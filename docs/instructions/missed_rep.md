# Missed rep
Missed rep depends on whether they chose RPE or percentage. First of all…
1) First: log the miss properly
When the athlete taps Missed rep, the app should ask one quick follow-up:
Too heavy
Pain / irritation
Technical error (only if confident)
That matters because we must distinguish between fatigue, pain, and normal progression issues. Pain should push variation changes; fatigue should push dose reduction; normal flatness should first be handled by smaller load/volume adjustments, not chaos.
2) If athlete is in RPE mode: treat the miss as an overshoot
The point of RPE is to avoid unnecessary misses by adjusting load on the day. For instance, RPE 7 by default stresses  that the athlete should have 3 reps in reserve. Which means they overshot. This is okay, because misjudgements happen. 
So in RPE mode, a missed rep should usually mean:
If the miss happens on the first work set
Recommend the athlete reduces load 2.5–5% immediately (again, in RPE, the exact number does not show, they have to do this themselves).
Re-run the set only if technique is good and the miss was not pain-related
Keep the same rep target, but stay at the lower end of the RPE target
Remember, out rulebook already uses roughly 2.5% per 1 RPE point in the low-rep strength zone, so a miss is a practical sign the set overshot the intended effort. A 5% drop is a good default when it clearly jumped past target.
If the miss happens on a later set, give the following recommendations:
Keep the last successful load as the ceiling for that day
Reduce the remaining sets by 2.5–5%, or
Keep the load and cut 1 set
If the athlete misses the final rep of the final set only
End the lift there
Mark it as minor overshoot
Treat it as a learning experience for judging future lifts. 
No need to overreact to one late-session miss.
3) Percentage mode: don’t stay rigid once a rep is missed
Here’s our rationale if the athlete is in the percentage mode. 
First miss on a main strength lift
Auto-offer 3 options for next set(s):
Continue at -2.5%
Continue at -5%
Continue at -7.5%
If the miss happens early
Treat it as either:
daily readiness was low, or
training max is slightly inflated (recommend them to check it)
For the rest of the session, drop one loading tier
For next week, freeze progression unless the athlete reports the miss was purely technical/setup-related
If the miss happens late
Assume fatigue accumulation more than bad programming
Keep the week the same, but reduce remaining work:
cut 1 set, or
use a 5% fatigue drop for back-off work
That lines up with the fatigue-drop logic in your book, where load is reduced after a hard top set rather than forcing the planned weight no matter what.
If the same lift has misses in 2 consecutive exposures
Do not advance %
Repeat the week or reduce the training max by 2.5–5%
Only change the whole scheme if the trend stays flat after that
That matches your rulebook: deload/dose-tweak first, scheme change later.
4) Special rule by exercise category
This part is important.
Primary strength lifts
Use the logic above.
Olympic lifts
These need separate handling. Your book explicitly notes that Olympic lifts may be missed even at moderate loads because the problem can be technical, not just intensity.
So for Olympic lifts:
After 1 technical miss, reduce 2.5–5%
Retry only if the miss was clearly technical and the athlete still looks sharp
After 2 misses, stop the lift and move to a simpler substitute:
clean pull
high pull
jump shrug
med-ball throw
Do not let the app treat these misses the same as a squat grind.
Ballistic / plyo / speed work
RPE is limited here, and “missed rep” is the wrong concept for many of these anyway. Your material says velocity work is better handled by %, feel, or velocity measurement.
So for these, log:
rep quality drop
landing quality drop
velocity loss
missed catch / bad throw
Adjustment:
reduce reps per set
extend rest
stop once quality clearly drops
Accessories / pull-ups / DB work
Do not overcomplicate these with percentage rescue logic. Your rulebook already filters true testing and precise % work mostly to primary lifts.
For accessories:
missed rep = end set
next set: reduce load or reps slightly
next session: repeat until completed cleanly
5) A very simple decision tree for the app
This is probably the best UX:
Missed rep detected → ask why → return one recommendation
Recommendation engine
Too heavy / fatigue → reduce 2.5–5%
Technique miss → retry once or reduce 2.5–5%
Pain → stop lift, swap variation
Second miss → stop main lift, no more heroics
Repeated misses across sessions → freeze progression or slightly lower training max
6) The simplest wording to show the athlete
You could display:
Missed rep logged. Best next step:
Lower load 2.5%
Lower load 5%
Cut 1 set
End lift for today
Swap variation
Then below that:
Next-session adjustment:
Repeat same load
Freeze progression
Lower training max slightly
Coach review flag
7) My recommended default rules
If you want one clean default system:
In RPE mode
1 miss early = -5%
1 miss late = -2.5% or cut 1 set
2 misses = end lift
2 sessions in a row with misses = repeat load next time
In % mode
1 miss early = drop one loading tier
1 miss late = fatigue drop or cut 1 set
repeated misses = freeze progression
repeated misses over 2 exposures = reduce training max 2.5–5%
That would be coach-like, simple, and consistent with the rest of your logic.
The one thing I would add for sure: don’t let a missed rep automatically trigger a scheme change. Your own rules are stronger when the app first tries dose adjustment, deload, or exercise variation.
