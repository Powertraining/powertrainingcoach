# RPE Rationale
Here’s the rationale to go by: Simple rule (1–5 reps, 2.5% per RPE)
For the same number of reps (1–5):
Every 1 RPE point ≈ 2.5% change in load
So if you have a known reference set (e.g. 3×5 @ RPE 8), you adjust like this:
RPE 9 ≈ +2.5% load
RPE 10 ≈ +5% load
RPE 7 ≈ −2.5% load
RPE 6 ≈ −5% load
Formula
If L_ref is the load at a given RPE for 1–5 reps:

L_new ≈ L_ref * (1+0.025*ΔRPE)

ΔRPE = (target RPE − reference RPE)

Example (5 reps)
You know:
100 kg × 5 @ RPE 8
Then:
5 reps @ RPE 9 →
100*1.025≈102.5→ 102.5 kg (or 102.5–105 depending on plates)
5 reps @ RPE 7 →
100*0.975≈97.5→ 97.5 kg
5 reps @ RPE 10 →
100*1.05≈105→ 105 kg
Same logic holds for 1–4 reps too, as long as you stay in that low-rep strength zone.
