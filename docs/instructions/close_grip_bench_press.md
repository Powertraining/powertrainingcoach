# Rule for Close Grip Bench Press
NOTE: ONLY WHEN USER SELECTS THE PERCENTAGE SYSTEM. 
If close-grip bench press is used, and no specific close-grip bench press 1RM has been entered or tested, estimate it as 95% of the athlete’s normal bench press 1RM. All percentage-based prescriptions for close-grip bench press are then calculated from this adjusted value, not from the regular bench press 1RM.
For the app display:
Estimated Close-Grip Bench Press 1RM
 Based on normal bench press 1RM ?
Tooltip / legend text:
This value is estimated from your normal bench press 1RM when no close-grip bench press max has been entered. Default estimate = 95% of normal bench press 1RM. All close-grip bench press percentages are based on this adjusted value.
