# Rules for Pull Ups/Chin Ups:
Pull Ups/Chin Up Rules
Even if the athlete chooses percentage-based loading, pull-ups are prescribed by RPE/RIR because bodyweight changes the true load and makes percentages confusing.

## App Rule Text
Pull-Ups / Chin-Ups
 Pull-ups are always prescribed using RPE/RIR, even when percentage loading is selected. This is because bodyweight already contributes heavily to the load, making percentage calculations less practical.
If the athlete cannot perform clean bodyweight pull-ups, use assisted pull-ups, band-assisted pull-ups, eccentric pull-ups, or lat pulldowns.
Once the athlete can perform clean bodyweight pull-ups, progress by adding reps first. When the athlete can perform around 8–10 clean reps, weighted pull-ups become available.

## Progression Rule
For assisted pull-ups / lat pulldowns
Progress like this:
Add reps until the athlete reaches the top of the rep range, then increase load slightly.
Example:
Week
Prescription
Week 1
3 × 6 @ RPE 7
Week 2
3 × 7 @ RPE 7–8
Week 3
3 × 8 @ RPE 8
Week 4
Increase load slightly, return to 3 × 6

For bodyweight pull-ups
Progress like this:
Add 1 total rep per session while keeping 1–2 reps in reserve.

For weighted pull-ups
Progress like this:
Use the same weight until all sets hit the top of the rep range at the target RPE, then add 1–2.5 kg / 2.5–5 lb.

## Very Simple Final Version
Use this as the actual app rule:
Pull-ups are RPE-based regardless of loading preference.
 If the athlete cannot perform clean bodyweight pull-ups, use assisted pull-ups or lat pulldowns.
 If the athlete can perform 1–9 clean pull-ups, use bodyweight pull-ups and progress reps.
 If the athlete can perform 10+ clean pull-ups, use weighted pull-ups and progress load when all sets are completed at the target RPE.
 Reduce sets during high combat-sport loading.
Key cues
Clean reps only. No kicking. Control the bottom. Pull chest toward the bar. Stop the set before form breaks.
What to log
Bodyweight, added weight if used, reps per set, RPE/RIR, and grip variation.
Next session
Test max clean bodyweight pull-ups. Then assign the athlete to one of the four levels above.
