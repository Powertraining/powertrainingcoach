# Session Spacing Function
Once the athlete has spread out their training sessions, the app should estimate session similarity and flag when highly overlapping sessions are scheduled too close together. Similarity should be based on shared region, shared training quality, and shared stress level, rather than exercise names alone. Sessions with high overlap in force, power, or fatigue demands—especially for the same region—should generally be separated by about 48 hours when possible, while lower-overlap sessions may be scheduled closer together. This spacing rule should be advisory, not absolute, since real-world schedules vary.
